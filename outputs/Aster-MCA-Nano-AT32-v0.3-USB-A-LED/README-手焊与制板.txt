Aster MCA Nano AT32 v0.3 — 蓝色双灯手焊版
发布：2026-10-09；工程样机，尚未实物验证。

本次改版
在嘉立创EDA原生工程内加入 LED1/PWR、LED2/RUN 和 R1/R2。
LED：两颗用户自备蓝色0603，Vf约2.5–3V；电阻：两颗0603 1kΩ，1%或5%，额定功率至少1/16W，常见丝印102。
PWR：V3V3 → R1 → LED1阳极，LED1阴极接GND；通电且3.3V电源建立后亮，不占MCU引脚。
RUN：V3V3 → R2 → LED2阳极，LED2阴极接U1 PB12（封装第25脚），网络LED_RUN；低电平点亮。
按Vf估算每灯约0.3–0.8mA，GPIO低电平压降会略减小电流；实际亮度用你的灯确认。
保持32×18mm板框、原有元件位置与数值，以及USB-A公头和SMA母座位置。AT32保留U3 TLV9061IDBVR。
在线工程：https://pro.lceda.cn/editor#id=b4dd280c0d714fd895c8442a7ab87cc4

制板要求
FR-4，2层，1oz铜；裸板32×18mm。普通绿色阻焊可用，过孔双面盖油。
成品板厚必须1.50±0.05mm，以匹配Amphenol 132289 SMA最大1.57mm的板厚要求。
不得无确认地改成1.6±10%常规板。若厂家不支持此板厚公差，需先重新确认SMA机械配合。
USB：CnC Tech 1001-011-01101；SMA：Amphenol RF 132289。附机械图供比对，替代料须逐项核对。
USB壳脚为2个2.50×0.90mm金属化长槽；另有2个直径1.10mm非金属定位孔。不可当成4个圆孔。
制板ZIP保留完整PTH/NPTH钻孔，去掉EDA额外重复的Via钻孔文件及无关钢网层。
最小设计线宽/铜间距0.15mm；新增RUN走线0.18mm。连接器两端不要留下妨碍安装的工艺边。

手焊与极性
面向元件面，USB在左、SMA在右：左上是LED1/PWR，左下是LED2/RUN；右邻电阻分别R1/R2。
两颗LED的阴极K都是左边焊盘1，朝USB端；阳极A为右边焊盘2。先用万用表二极管档确认手头LED极性，勿只凭外观印记猜测。
新增LED和电阻在顶面；推荐先焊IC与小件，再焊LED，最后固定USB/SMA。SMA上下两面地脚都要焊。
AT32：R21默认0Ω实装，R22默认不装；详见BOM-DNP.csv。U3使用TLV9061IDBVR/SOT-23-5，勿套用不同封装引脚。

运行灯的固件约定
PB12先将输出锁存置高，再配置为输出，避免初始化时误闪；高=灭、低=亮。
建议约1Hz心跳表示程序仍在运行，避免逐事件闪灯或高频PWM给模拟采样引入额外干扰。
可后续以闪烁节奏表示故障，无需增加第三颗灯；本包没有实现或验证这段固件。
上电只有PWR亮、RUN不闪，不能直接判断硬件故障；RUN必须由已烧录固件控制。

首次上电
断电检查IC/二极管方向、焊桥以及5V/3.3V对地；SMA不接信号，先用限流USB供电。
测TP2约3.3V、TP6约1.65V，再检查LED与模拟静态输出。电流异常先断电。
SMA仅接低压电压脉冲，不含CSA，不能直接接探测器高压。
先用小幅度、低计数率脉冲观察削顶/振荡/基线，再进行ADC采样和能谱验证；完整MCA固件仍待实现。
